Página inicial — desktop (≥1024 px)

Mesmo conteúdo, mesma ordem, mesmos tokens — o que muda é a grade. Container de 1180px, calha de 32px, navegação horizontal na barra marrom (a gaveta só existe abaixo de 1024px), herói em duas colunas com o card avançando 48px sobre a imagem, tiles em 4 colunas, setores em 3 colunas (o carrossel deixa de existir), mídia em 3 cards e rodapé em 3 colunas. Escala tipográfica sobe: H1 46px, H2 30px, H3 22px, corpo 15–17px.

Breakpoints
  • <640px — mobile: coluna única, gaveta, carrossel
  • 640–1023px — tablet: tiles 2×2, setores 2 colunas, gaveta mantida
  • ≥1024px — desktop: grade completa, navegação horizontal
  • ≥1240px — container travado em 1180px, centralizado
O que não muda no desktop
  • Sombra dura, sem blur (5–8px conforme o bloco)
  • Zero cantos arredondados fora de controles
  • Barra de acessibilidade visível no cabeçalho
  • Faixa listrada só 2× por página
  • Alvo mínimo de 44px também no mouse

Como adaptar o projeto existente

  1. Importar Bitter (300–700 + itálico) e remover qualquer sans do CSS legado.
  2. Copiar tokens.css e carregá-lo antes de tudo.
  3. Mapear as cores antigas pela tabela do README.md — sem criar cor nova.
  4. Implementar componentes na ordem: botão → card → tile → cabeçalho → gaveta → barra de acessibilidade → lista de mídia → rodapé.
  5. Recriar a home a partir de index.html (estrutura e cópia exatas).
  6. Rodar o checklist de QA do README em 320, 390 e 430 px.
